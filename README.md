# 🏠 Rent Management System

A web-based **Rent Management System** built with **Python and Django** to manage properties, tenants, rent records, and reports.

## ✨ Features

- 📊 Dashboard
- 🏠 Property management
- 👤 Tenant management
- ➕ Add tenants
- 📋 View tenant details
- 📜 View past tenants
- 💰 Rent management
- 📦 Bulk rent operations
- 📈 Reports
- 🗑️ Delete tenants/properties with confirmation
- 📝 Django forms and reusable templates

## 🛠️ Technologies Used

- **Python**
- **Django**
- **HTML**
- **CSS**
- **SQLite**
- **Pipenv**

## 📌 About the Project

The Rent Management System is a Django web application designed to make it easier to manage rental properties and tenants.

The application provides a dashboard along with separate sections for managing properties, tenants, rent operations, and reports.

It was built as a project to learn and practice Django web development, database operations, forms, templates, and CRUD functionality.

## 📂 Main Sections

| Section | Description |
|---|---|
| 📊 Dashboard | Provides an overview of the application |
| 🏠 Properties | Manage rental property information |
| 👤 Tenants | Add and manage tenants |
| 📜 Past Tenants | View previous tenant records |
| 💰 Rent | Manage rent-related information |
| 📦 Bulk Rent | Perform rent operations in bulk |
| 📈 Reports | View rent/property-related reports |
